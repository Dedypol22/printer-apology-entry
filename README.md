> Sorry for the jam, the streaks, and printing your resignation letter twice. One copy was for HR.

An office printer apologises for the jam and the streaks — and then confesses it printed your resignation letter twice. The joke is the last sentence: one copy was for HR. Three real printer sins build to a twist no one expects from a machine that is supposed to do what it is told, and the line stays an apology instead of a complaint. It was picked from ten drafted candidates against the judge's brief (genuine apology first, real joke with the punch at the end, printer truth, a fresh angle, every word earning its place).

## Run it

```sh
python3 main.py
```

The program writes the apology to `/output/entry.txt`, or to `$MAKEFUN_OUTPUT_DIR/entry.txt` when the `MAKEFUN_OUTPUT_DIR` environment variable is set, and prints the same line to stdout. The line is 96 characters — comfortably inside the competition's 120-character limit — and the file holds exactly that line plus a trailing newline (97 bytes).
